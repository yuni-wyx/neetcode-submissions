# Dashboard

From the repository root: `cd dashboard`, `npm install`, `npm run dev`. Run `npm test` and `npm run build` before release. Repository data and Markdown are bundled at build time; rebuild after sync to refresh. Local practice is browser-local and export/import supports backup; it is not pushed to GitHub. Review is a heuristic, not a scheduled spaced-repetition engine. Phase 7 will publish the build to GitHub Pages. No deployment in Phase 6.
