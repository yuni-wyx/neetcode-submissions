# Practice and mastery

Public repository: store technical learning summaries only, not raw conversations or personal identifiers. Dates use conversation date labels when known; otherwise null. A documented practice count is a lower bound; historical total remains unknown. Submission counts are separate. Reported completion is not a counted session. Mastery is assessed independently: 0 confirmed unpracticed, 1 solution needed, 2 completed with hints, 3 independent with debugging, 4 independent with complexity explanation, 5 timed independent with follow-ups. Null means unknown. Append one session per problem per distinct practice session to attempts.json, and evidence-backed dated evaluations to assessments.json. Generated tables and progress.csv are regenerated by Phase 3; do not edit them directly.
